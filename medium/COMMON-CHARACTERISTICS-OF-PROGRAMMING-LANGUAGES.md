# Common Characteristics of Programming Languages

## Introduction

Programming languages are often perceived as difficult to learn, but their core fundamentally hinges on three elements: step atomization, data processing, and logical judgment. These three elements are indispensable for determining whether a program can run successfully. If you only know data processing and logical judgment but cannot break down steps, you won't understand why the syntax is used in a particular way. This is precisely why I emphasize step atomization as the foremost priority. Consider the classic example: how many steps are required to put an elephant in a refrigerator? Programming follows the same principle. Often, the interfaces are readily available, but the real challenge lies in analyzing which processes are needed to fulfill each requirement. This is the most difficult step—syntax comes second, as it can always be looked up on the official website. Additionally, when programming, you must consult the official documentation. Thoroughly understand the usage of every function, including their return values, before starting development. Doing this upfront significantly reduces your workload later on.

## Common Operations in Programming Languages

Common programming operations include file management, string processing, frontend/backend requests, data processing, exception handling, coroutines, regular expressions, and more. Each programming language possesses unique characteristics, such as C++'s pointers and Lua's tables. Languages like Python, Rust, Bash, HTML, CSS, and JavaScript are essentially branches of the C++ programming language family, each with distinct syntax. Different languages serve different purposes: C++ prioritizes high performance and excels in embedded development, Bash is ideal for automation scripts, while Lua is well-suited for hot reloading.

## File Management

Common file management operations include writing, appending, reading, creating, deleting, copying, moving, and so on. If you're learning programming, file handling is one of the very first operations you'll encounter—it's among the most fundamental tasks in programming. Many programming languages have already encapsulated functions for handling these operations. You can typically find them by searching online using keywords related to the specific file operation you need.

## String Processing

Common operations in string processing include appending, deleting, modifying content, searching for keywords, concatenating, formatting, copying, calculating length, comparing the contents of two strings, and so on. String manipulation is frequently encountered when writing programs, especially when handling data. In practical development, we sometimes perform formatting operations on strings. For instance, we might want a program to output strings in a specific format, or after reading a file, we might wish to remove all spaces within it.

## Frontend and backend requests

In computing, when we connect to the internet, data packets are only sent when we genuinely need them. Each device has its own unique IP address. Our optical network terminal (ONT) represents the wide area network (WAN), while our router constitutes the local area network (LAN). As the name suggests, a WAN is a network accessible to the public. A LAN, on the other hand, is created when you connect to a router, which automatically assigns an IP address to each device to facilitate data exchange between them. The MAC address serves as the unique identifier for each device, and some devices even support random MAC addresses.

## Data Processing

For instance, when we access data on the internet, some is in JSON format, some in JSON5, and some in YAML format. At this point, we need a programming language to parse it, extract the information within, and convert it into data we humans can understand.
